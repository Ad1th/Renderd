Process

Release Process

Per REPO-0001 §17, releases follow a structured checklist to ensure quality and reproducibility.

Pre-Release Checklist

  • All CI checks pass on main branch (macOS + Windows)
  • cargo deny check — no security advisories or license violations
  • Latency benchmarks validated against RFC-0002 §19 targets
  • CHANGELOG.md updated with all [Unreleased] items
  • Version bumped in all Cargo.toml files
  • Git tag created: v{major}.{minor}.{patch}

macOS Release

  • .app bundle assembled via tools/bundle-host/
  • Code-signed with Apple Developer ID
  • Notarized via notarytool
  • Stapled with stapler
  • GitHub Release artifact: renderd-host-{version}-aarch64.dmg

Windows Release

  • Built via windows-2025 GitHub Actions runner
  • GitHub Release artifact: renderd-viewer-{version}-x64.exe

Two files, one for each computer.

Renderd has two parts. The host runs on your Mac and makes the second display. The viewer runs on your Windows PC and shows it. Both are free. The Mac file is {{ (rel.mac.size / mb) | round(precision=1) }} MB and the PC file is {{ (rel.win_x64.size / mb) | round(precision=1) }} MB.

What you need

Mac
Apple Silicon (M1 or later) with macOS 13 Ventura or later. Intel Macs are not supported.
PC
Windows 10 or 11, on x64 or ARM64. Pick the file that matches the PC's processor.
Network
Both computers on the same local network, on Wi-Fi or Ethernet. The Mac listens on UDP port 4433.
Video
The PC uses H.264 by default. HEVC needs the HEVC Video Extensions from the Microsoft Store.
First run From download to second display Six steps

The first run, step by step.

You do this once. After the PIN, the two computers know each other and connect on their own.

On the Mac

  1. 1
    Unpack and start the host in Terminal, in the folder with the download.
    tar -xzf {{ rel.mac.name }}
cd {{ host_dir }}
./renderd-host
  2. 2
    If macOS blocks it because it cannot check the developer, clear the download flag and start it again.
    xattr -d com.apple.quarantine renderd-host
./renderd-host
  3. 3
    Allow Screen Recording when macOS asks, or in System Settings, Privacy & Security. Then stop the host with Control-C and start it again. macOS applies the permission only after a restart. The host then prints the address of the Mac.

On the PC

  1. 4
    Unzip and run renderd-viewer.exe. If Windows SmartScreen stops it, click More info, then Run anyway. If Windows Firewall asks, allow it on private networks.
  2. 5
    It finds the Mac on its own. If it does not, for example across a VPN or two subnets, give it the address the Mac printed:
    renderd-viewer --host 192.168.1.20:4433
  3. 6
    Type the PIN. The Mac shows a six-digit PIN once. Type it on the PC. The PC's screen is now a display of the Mac. Arrange it in System Settings, Displays.
Checks Before and after SHA-256

Check the files

Each release has a SHA256SUMS.txt. Make the hash of your download and compare it with the line for that file. If the two are not the same, do not run the file.

Mac, in Terminal

shasum -a 256 {{ rel.mac.name }}

PC, in PowerShell

Get-FileHash .\{{ rel.win_x64.name }}

Or build it yourself from the source on GitHub.

If nothing appears

  • Check that the host still runs on the Mac and that you allowed Screen Recording, then restarted it.
  • Give the viewer the address with --host. Discovery does not cross subnets or VPNs.
  • On a PC without HEVC, keep the default codec, H.264.

More checks, and what each log line means, are in the README. Still stuck? Open an issue.

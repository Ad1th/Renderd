Compatibility

Supported Platforms

Renderd is a purpose-built tool: macOS as the host, Windows as the viewer. Platform support is tightly scoped to maximize hardware pipeline utilization.

Platform Details

🍎

macOS Host

Runs renderd-host

Minimum OS macOS 14.0 (Sonoma)
Also tested macOS 15 (Sequoia)
Architecture aarch64-apple-darwin (Apple Silicon)
CPU Apple M1 or later
Process model Login Item Agent (SMAppService)

Required APIs

  • ScreenCaptureKit (macOS 12.3+) — zero-copy display capture
  • VideoToolbox — hardware H.265/H.264 encoder
  • Bonjour / dns_sd.h — mDNS advertisement
  • Keychain Services — PairToken storage
  • SMAppService (macOS 13+) — Login Item registration

Required Entitlements

com.apple.security.app-sandbox
com.apple.security.screen-recording
com.apple.security.network.client
com.apple.security.network.server
ℹ️
Intel (x86_64) Macs are not a supported target. ScreenCaptureKit and VideoToolbox hardware encoding on Intel produce substantially higher latency and the IOSurface zero-copy path behaves differently on discrete GPU Macs.
🪟

Windows Viewer

Runs renderd-viewer

Minimum OS Windows 10 (primary supported)
Windows 11 Expected to work
Windows 7 Planned where feasible
Architectures x86_64-pc-windows-msvc, aarch64-pc-windows-msvc
GPU requirement Any D3D12-capable GPU (most discrete/integrated GPUs from 2015+)

Required APIs

  • Direct3D12 Video Decode — hardware H.265/H.264 decoder
  • DXGI Swap Chain — conditional ALLOW_TEARING present
  • winit — Win32 message pump & DPI handling
  • DnsServiceBrowse (Win32, Win10 v1703+) — mDNS browse
  • Windows Credential Manager — PairToken storage

Hardware Decoder Support

DecoderCoverage
D3D12VA (primary)Any D3D12 GPU, driver-agnostic
NVDEC (fallback)NVIDIA GPUs (GTX 900+)
Intel QuickSyncIntel Arc / Iris Xe

Scope

Out of Scope for v1.0

The following platforms and features are explicitly out of scope for the initial v1.0 release. See the Roadmap for planned future versions.

🚫

Remote Input

No keyboard/mouse forwarding. Renderd is a display receiver only, not a remote desktop system.

🚫

Internet / WAN

No relay or NAT traversal in v1.0. LAN-only (peer-to-peer). WAN relay planned for v2.0.

🚫

Linux Host or Viewer

Linux support (PipeWire + VA-API for host; Vulkan for viewer) is planned for v1.1.

🚫

Audio Streaming

Audio via Opus codec is planned for v1.2.

🚫

Multi-Monitor

One host display to one viewer display. Multi-monitor planned for v1.3.

🚫

Mobile (iOS/Android)

Mobile viewer (Metal + VideoToolbox for iOS/iPadOS) planned for v2.0.

Development Setup

Build Prerequisites

🍎 macOS (Host Development)

  • macOS 14.0+ (Sonoma) or later
  • Apple Silicon Mac (M1 or later)
  • Xcode Command Line Tools: xcode-select --install
  • Rust stable 1.80+: rustup toolchain install stable
  • Target: rustup target add aarch64-apple-darwin
# Clone and build
git clone https://github.com/Ad1th/renderd
cd renderd
cargo check --workspace

🪟 Windows (Viewer Development)

  • Windows 10 or later
  • Visual Studio 2022 with C++ Workload
  • Windows 10 SDK (or Windows 11 SDK)
  • Rust stable 1.80+: install from rustup.rs
  • Target: rustup target add x86_64-pc-windows-msvc
# Check Windows-specific crates
cargo check -p renderd-viewer
cargo check -p renderd-viewer `
  --target x86_64-pc-windows-msvc

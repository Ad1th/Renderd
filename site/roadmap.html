Milestone 1: Repository Bootstrap & Infrastructure

Complete Issues #001–#012

Strictly workspace configuration, tooling enforcement, CI workflows, and build automation. No feature code.

Cargo workspace rust-toolchain.toml clippy.toml deny.toml nextest.toml CI workflow Security audit Bench workflow CODEOWNERS Issue templates Typos check Docs workflow
✅

Milestone 2: Foundation Layer

Complete Issues #013–#022

Protobuf schema, renderd-proto crate (generated types + newtypes + envelope dispatch), and renderd-config crate (Figment-based layered config loader).

renderd.proto schema prost codegen FrameId / FragmentId newtypes BitrateKbps / VsyncPeriodNs MessageKind dispatch SessionHello validation RenderdConfig schema ConfigBuilder (Figment) ValidateConfig trait ConfigError hierarchy
🔨

Milestone 3: Core Data Structures & Utilities

In Progress Issues #023–#035

Fragment header codec, sliding-window reassembly buffer, high-resolution monotonic clock wrapper, clock offset estimator, rolling statistics, ABR state machine, and ABR engine.

renderd-frame FragmentHeader codec FragmentFlags bitfields ReassemblyBuffer (W=4) renderd-clock MonoInstant wrapper ClockEpochEstimator RollingStats ring buffer renderd-abr AbrState machine AbrEngine TelemetryReport
4

Milestone 4: FFI Layer (VideoToolbox & SCKit Shims)

Planned Issues #036–#047

macOS-only FFI crates: C shim for VideoToolbox (VTCompressionSession), and Objective-C bridge for ScreenCaptureKit (SCStream). These are the only crates where unsafe is permitted.

renderd-vt-sys VTCompressionSession C shim cc crate build.rs renderd-sc-sys SCStream ObjC bridge IOSurface FFI
5

Milestone 5: Service Layer (Net, Keychain & Discovery)

Planned Issues #048–#063

QUIC connection/datagram abstraction (renderd-net), cross-platform keychain abstraction (renderd-keychain), and mDNS peer discovery (renderd-discovery).

6

Milestone 6: Algorithm Layer (ABR & Clock Sync)

Planned Issues #064–#075

Integration of ABR engine with QUIC feedback loop and full vsync phase synchronization protocol from RFC-0002 §7.

7

Milestone 7: Host Application (renderd-host)

Planned Issues #076–#088

macOS Login Item Agent: SCStream capture → VideoToolbox encode → quinn send. Menu bar UI via tray-icon + AppKit. SPAKE2+ pairing ceremony. macOS app bundle, entitlements, and notarization.

8

Milestone 8: Viewer Application (renderd-viewer)

Planned Issues #089–#100

Windows 10+ viewer client: quinn receive → fragment reassembly → D3D12 decode → DXGI present. System tray UI. SPAKE2+ pairing. Vsync phase reporting. Automatic reconnect with mDNS re-discovery.

9

Milestone 9: Benchmarks & Tooling

Planned

latency-bench tool measuring glass-to-glass latency. Criterion benchmarks for fragment codec and reassembly. Performance regression validation before release.

10

Milestone 10: Pre-Release Audit & v0.1.0

v0.1.0

Security audit (cargo-deny, cargo-audit), latency validation against RFC-0002 targets, documentation review, and first public release on GitHub.
